A Python-based Restaurant Order Management System for managing menus, tables, orders, billing, kitchen queues, and sales reports.
# Restaurant Order Management System Using Queue

## About the Project
This project manages restaurant orders using the Queue data structure in Python.

## Objective
To understand the working of Queue and use it to manage restaurant orders efficiently.

## Data Structure Used
- Queue

## Programming Language
- Python

## How It Works
1. Add new customer orders to the queue.
2. Orders are stored in the order they are received.
3. The first order in the queue is selected for processing.
4. The selected order is prepared and served.
5. The completed order is removed from the queue.
6. The process continues until all orders are completed.

## Example

Orders:
- Order 1
- Order 2
- Order 3

Serving Order:
- Order 1 → Order 2 → Order 3

## Time Complexity
O(n)

## Space Complexity
O(n)

## Conclusion
This project demonstrates how a Queue can be used to manage restaurant orders and understand the practical application of the FIFO principle.
